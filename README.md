# 演習01　Git を使ってみる

ゲームのサンプルを使い、ターミナルと VS Code の両方で Git を練習します。変更履歴、差分、ブランチを順に扱います。Git とターミナルが初めての方も参加できます。教材の目安は60分未満です。

## 始め方

1. GitHub にサインインし、[このテンプレートから演習を作成する](https://github.com/new?template_owner=ctct-edu&template_name=introduction-to-git&owner=%40me&name=skills-introduction-to-git&description=Exercise:+Introduction+to+Git&visibility=public) を開きます。**Repository name** に `skills-introduction-to-git` が入っていることを確認します。**Owner** と公開範囲を確認して **Create repository** を選びます。
2. 自分のリポジトリが作成されたら、20秒ほど待ってページを再読み込みします。
3. 自分のリポジトリの README から演習 Issue を開き、日本語のステップ案内に沿って操作します。
